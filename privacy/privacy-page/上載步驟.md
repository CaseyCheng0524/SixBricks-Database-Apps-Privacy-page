# 私隱政策網頁：放上 GitHub Pages

上載後的網址會是：

```
https://<你的帳戶>.github.io/<專案名稱>/privacy/
```

## 1. 上載網頁

1. 打開 GitHub 上的 Six Bricks 專案
2. 按「Add file › Upload files」
3. 把 `privacy-page` 資料夾**裏面的** `privacy` 資料夾拖進去，GitHub 上會出現 `privacy/index.html`
4. 按「Commit changes」

## 2. 開啟 GitHub Pages（只需做一次）

1. 在專案頁按 **Settings**
2. 左邊選 **Pages**
3. 「Build and deployment › Source」選 **Deploy from a branch**
4. 「Branch」選 **main**，資料夾選 **/ (root)**，按 **Save**
5. 等 1 至 3 分鐘，頁面頂部會顯示網址

> 專案必須是 **Public**，否則免費帳戶不能用 GitHub Pages。如果專案是 Private，可以另開一個 Public 專案，只放 `privacy` 資料夾。

## 3. 測試

- 打開 `https://<你的帳戶>.github.io/<專案名稱>/privacy/`
- 頁面會按瀏覽器語言自動顯示。右上角可切換 6 種語言
- 指定語言的網址：在後面加 `?lang=en`、`?lang=zh`、`?lang=zhs`、`?lang=es`、`?lang=fr` 或 `?lang=it`

## 4. 填到商店

- **App Store Connect：** App 資訊 › 私隱政策網址
- **Google Play Console：** 應用程式內容 › 私隱權政策

建議填英文版網址：`…/privacy/?lang=en`
